# interview-assistant 文档索引

本目录用于记录 `interview-assistant` 的学习路线、完成度对比、实施计划和关键架构决策。项目以远程仓库 `https://gitee.com/SnailClimb/interview-guide` 为参考实现，但不会机械复制参考项目代码，而是按学习和真实开发节奏逐步靠齐。

## 文档阅读顺序

1. `项目完成度审计.md`：先了解当前已经完成什么、还缺什么、和参考项目差距在哪里。
2. `学习路线图.md`：再按阶段学习，每个阶段都有目标、参考文件和验收方式。
3. `实施计划.md`：实际开发时按任务推进，每个任务都有验收标准和验证方法。
4. `面试题库.md`：准备项目面试问题，按替代方案、代价、失败场景和现场改动四个角度复习。
5. 项目根 `README.md`：查看项目介绍、启动方式、接口清单和浏览器验收顺序。
6. `study/前端展示层约定.md`：前端枚举中文化、时间与文件大小格式化、状态徽章组件的落地约定。
7. `study/Redis基础与环境搭建.md`：Redis 引入背景、核心命令实测、Redisson 接入过程和踩坑记录。
8. `decisions/ADR-001-参考项目驱动的渐进式实现路线.md`：理解为什么采用“参考项目驱动 + 分阶段演进”的方式。
9. `decisions/ADR-002-前端参考优先实现.md`：理解为什么前端先对齐 `interview-guide`，项目完整后再差异化。

## 使用原则

- 每次只做一个小任务，完成后验证。
- 先读参考项目，再看当前项目，再动手实现。
- 当前阶段允许简化，但文档中必须标明后续如何向参考项目演进。
- 代码实现前先确认任务的验收标准。
